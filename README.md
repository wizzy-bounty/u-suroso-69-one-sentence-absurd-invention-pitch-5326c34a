# One-Sentence Absurd Invention Pitch

Entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on make.fun.

The pitch: a refrigerator that treats forgotten leftovers like tenants who have overstayed their lease — serving them formal eviction notices, complete with a 24-hour grace period and a small-claims court date for the lasagna. One sentence, deadpan, and the joke lives in the invention itself.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` and validates it against the competition gate first: one sentence, 1–220 characters, not whitespace only. The program exits non-zero with a clear message if the pitch ever stops being valid.
